# MD. Nazrul Islam - Professional Portfolio

A modern and interactive professional portfolio website built with ASP.NET Core MVC.

## Technology Stack

- C#
- ASP.NET Core MVC
- Entity Framework Core
- MS SQL Server
- HTML
- CSS
- JavaScript
- Bootstrap

## Project Purpose

This portfolio is designed to present professional experience, education, technical skills, projects, tools, and contact information through a dynamic web application.

## Features

- Professional protfolio website
- Dynamic content management
- Project showcase with dedicated detils pages
- Admin panel
- Contact form
- Massage management
- Email and WhatsApp contact options
